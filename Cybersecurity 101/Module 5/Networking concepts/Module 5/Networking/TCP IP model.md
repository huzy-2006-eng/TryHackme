# TCP/IP MODEL
1. Stands for Transmission Control Protocol and was developed in the 1970s by the Department of Defense(DoD).

2. One of the strengths of this model is that it allows a network  to continue to function as parts of it are out of service, for instance, due to a military attack.

## Layers of  TCP/IP:
1. Application layer:
The OSI model application(7), presentation(6) and session(5) layers are grouped into the application layer in TCP/IP Model.

2. Transport Layer: This is layer 4.

3. Internet Layer: This  is layer 3. The OSI model's network layer is called internet layer in TCP/IP.

4. Network Access Layer: This is layer 2.

#### Many modern networking textbooks show the TCP/IP model as five layers instead of four.
